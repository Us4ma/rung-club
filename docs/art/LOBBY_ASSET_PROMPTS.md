# Lobby illustration provenance

Generated with the built-in image-generation tool, with no API key, paid service, or new dependency. The approved desktop/mobile images inform layout and palette; neither is used as a flattened UI background. Existing `characters/dealer-female.webp` and `backgrounds/lounge.webp` are reused without character replacement.

Three isolated transparent illustrations are converted to responsive WebP (320 and 640 px) in `apps/web/public/art/lobby/`. All six files total 398,830 bytes (389.5 KiB). The mobile renderer selects the smaller variant when suitable. No ranks, ownership, scores, rewards or gameplay behavior depend on these decorative images.

Each prompt used this shared specification:

> Use case: stylized-concept. Asset type: isolated premium mobile card-game mode illustration, transparent background. Style: refined polished 3D game illustration, warm golden lighting, readable uncluttered silhouette, believable materials, restrained detail. Composition: centered compact square illustration with generous transparent margins, objects completely inside frame, strong small-size readability. No environment, no panel, no UI, no buttons, no lettering other than correct playing-card ranks. Emerald-and-gold card-room visual identity. Deliver only this independent illustration.

Subjects:

- **band:** Three face-down royal-blue playing cards with fine gold filigree and a simple spade on each back, one upright center and two tilted behind, a small tasteful brass crown resting on the upper card. Royal-blue velvet ribbon below. No coins or currency.

Holding two ivory playing cards, a teal bow tie, half-body portrait with small rounded arms. Short teal velvet ribbon beneath. No coins or currency.
